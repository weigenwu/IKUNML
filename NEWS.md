# IKUNML 0.1.1

- Added bundled example data and a workflow vignette.
- Added HTML and Excel reports.
- Added YAML/list config runner.
- Added stability selection, validation, and nested cross-validation helpers.
- Added runtime, metadata, and parameter exports.
- Added random startup messages with `options(IKUNML.startup = FALSE)` support.
- Renamed the public SVM method label to `SVM` while retaining old aliases.
- Added GitHub Actions `R CMD check`.
